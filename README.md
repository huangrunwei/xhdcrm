# XHD CRM
#### 介绍
XHD CRM（小黄豆CRM）是一款完全开源免费、MIT协议、私有化部署的国产轻量级客户关系管理系统。本次 V3.0 为全架构从零重构大版本，彻底迭代替换老旧 V1.17、V2.0 版本代码，全面升级现代化 .NET 技术栈，主打轻量高效、低耦合、易部署、极易二次开发、无用户数限制、无任何商业授权捆绑。
项目完全针对国内中小企业销售业务场景开发，完整覆盖客户全生命周期管理，所有业务数据私有化自留，彻底解决商用CRM收费、数据托管、功能受限、无法定制等痛点。
项目核心定位：专为 .NET 开发者打造的高质量开源CRM，代码规范、架构清晰、注释完善、可扩展性拉满，适合学习实战、企业自用、深度定制开发。
#### 技术栈（V3.0 全新现代化架构）
V3.0 对比历史 V1.17 / V2.0 版本完成全套技术栈换代，彻底摒弃老旧杂乱架构，技术体系统一、规范、高性能：
- 后端框架：.NET 8 高性能跨平台框架，启动更快、GC机制优化、支持程序裁剪发布、资源占用极低，兼容 Windows / Linux 部署
- 核心ORM：全线采用 FreeSQL 开源ORM框架，替代传统EF、手写SQL模式，支持动态查询、批量操作、事务管理、数据审计、多库适配，大幅提升开发与运行性能
- 前端框架：基于 Layui 稳定版本深度重构，统一UI组件、表单校验、弹窗逻辑、页面渲染规则，页面加载速度提升60%+
- 数据库支持：兼容 MySQL、SqlServer 主流企业级数据库
- 部署方式：支持 Kestrel 原生部署、IIS 部署、Docker 容器化部署
- 架构设计：采用简易 DDD 领域驱动分层架构，控制器、服务层、仓储层、模型层完全解耦
- 开源协议：MIT 开源协议，个人、企业均可免费商用、二次开发、私有化部署，无任何授权限制
#### 版本重大升级说明（历史版本 V1.17/V2.0 → V3.0）
重要说明：V3.0 为完整重构版本，前后端代码、项目架构、数据层逻辑、工程结构全部重写，与 V1.17、V2.0 版本代码无复用关系，属于新一代全新架构版本。
1. 底层架构全方位重构
彻底推翻旧版本杂乱臃肿的项目结构，重新标准化分层，清理全部冗余代码、废弃逻辑、重复方法。全局统一依赖注入、统一异常捕获、统一日志输出、统一接口返回格式，项目架构现代化、规范化，新手也能快速读懂源码、上手二次开发。
2. 全面接入 FreeSQL 数据框架
旧版本数据层逻辑混乱、硬编码SQL多、维护成本高。V3.0 全线迁移 FreeSQL，彻底优化数据底层能力：
- 实体自动映射，无需手动编写建表语句
- 链式优雅查询，彻底告别繁琐SQL拼接
- 支持批量增删改、软删除、数据脱敏
- 强事务机制，保障业务数据一致性，杜绝数据错乱
- 数据库迁移、版本升级更便捷、稳定
3. .NET8 性能全面跃升
升级 .NET8 全新框架后，程序启动速度、并发处理能力、接口响应速度、内存占用均大幅优化。支持裁剪发布，程序体积更小、资源消耗更低，低配服务器也能流畅稳定运行，完美适配小微企业低成本部署需求。
4. Layui 前端全量优化重写
针对旧版本前端卡顿、组件混乱、适配差、BUG多等问题全方位重构优化：
- 全量重构列表、表单、弹窗核心页面逻辑
- 优化表格渲染、分页加载、懒加载机制
- 统一全站UI样式，剔除冗余代码与无效样式
- 优化移动端自适应效果，手机端访问体验大幅提升
- 修复旧版弹窗重叠、表单重置、数据回显等遗留BUG
5. 三级精细化权限体系重构
全新升级 菜单权限 + 按钮权限 + 数据权限 三级权限架构，权限逻辑完全解耦。支持角色批量授权、用户单独授权、部门数据隔离，可适配多部门、多岗位、多级员工的企业精细化管控场景，满足正式办公投产使用。
6. 系统安全与运维能力升级
- 新增文件下载防盗链机制，防止资源恶意爬取盗用
- 全局日志分级记录，精准定位问题，方便日常运维排查
- 强化接口安全校验，拦截非法请求
- 修复旧版本遗留安全漏洞与逻辑缺陷，系统稳定性大幅提升
#### 核心业务模块
V3.0 完整继承并增强历史版本全部成熟业务能力，功能闭环、可直接投产使用：
- 客户管理：客户档案、客户分类、客户来源、跟进状态、客户公海、客户查重
- 联系人管理：多联系人绑定、职位/联系方式/微信信息维护

- 合同管理：合同录入、附件上传、状态管控、到期提醒
- 数据报表：销售看板、客户统计、业绩分析、回款数据可视化
- 权限管理：用户、角色、菜单、数据权限精细化配置
- 系统设置：参数配置、日志管理、数据备份、基础字典维护
